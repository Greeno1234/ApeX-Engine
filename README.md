# ApeX-Engine
ApeX Game Engine

## How to build
- open root directory in terminal
- run the command "cmake -B build"
- the build files will be stored in ApeX-Engine/build
- IMPORTANT! copy the files from /contrib/cl-windows-x86_64 directly into the newly created build folder
- open the solution inside the build directory
- set one of the demos as the startup project
- run the local windows debugger

## Current features
- 3D graphics, .obj 
- audio manager
- keyboard input
- Entity Component System (ECS)
